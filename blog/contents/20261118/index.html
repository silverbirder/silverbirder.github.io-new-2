Technology Radar が今月4日に Vol. 35 を公開しました。

その中で、ast-grep というのが気になりました。

ast-grep

ast-grep | structural search/rewrite tool for many languagesast-grep is a fast and polyglot tool for code structural search, lint, rewriting at large scale.ast-grep.github.io

Rust製の AST（抽象構文木）で grep できます。
サポート言語は、以下のものみたいです。

  • C
  • C++
  • Rust
  • Go
  • Java
  • Python
  • C#
  • JavaScript
  • JSX
  • TypeScript
  • TSX
  • HTML
  • CSS
  • Kotlin
  • Swift
  • JSON
  • YAML
  • HCL
  • Lua
  • Nix

ast-grep では 検索・置換・静的解析ができます。

かゆいところに

静的解析で推奨設定のまま使っていることが私は多いのですが、
開発しているとプロジェクト特有のルールを守りたくなることがあります。
層によってやって良いこと、やってはいけないことというのを決めたりします。
例えば、通信できる層、状態を管理して良い層などです。
これらを守るためには、独自のルールをJavaScript等で無理やり描かせるのですが、
初見で読めないことが多いし精度もあまり高くありません。（個人談）

ast-grep の場合、yamlで宣言的に valid・invalidなルールを書くことができ、
一目瞭然（？）にルールがわかりやすくなります。
また AST に基づくので、より細かいルール設定を作ることができるので、
痒い所に手が届く、しかも早い！
結構便利そう？と思っています。

終わりに

Technology Radar も、AI ばかりで飽き飽きしちゃいました。

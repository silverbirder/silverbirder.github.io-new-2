# 機能: 公開記事をまとめて取得する

## シナリオ: 公開記事が1,000件あるブログをビルドする

- 前提 公開用アーカイブに1,000件の記事がある
- もし ビルド用の記事を取得する
- ならば GitHub APIの呼び出し1回で全記事を取得できる

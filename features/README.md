# 機能: 公開記事をまとめて取得する

## シナリオ: 公開記事が1,000件あるブログをビルドする

- 前提 公開用スナップショットに1,000件の記事がある
- もし ビルド用の記事を取得する
- ならば CMSに接続せず、スナップショットから全記事を読み込める

- 前提 元の幅1280ピクセル、高さ960ピクセルの画像を罫線6行に指定する
- もし 記事の配信画像を生成する
- ならば 幅208ピクセルと2倍密度向けの幅416ピクセルを選べる
